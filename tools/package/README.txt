敲门 KNOCK —— 2D/3D 恐怖 Demo
================================

怎么玩
  1. 先把整个压缩包解压出来（不要在压缩包里直接双击）。
  2. 双击 Play-Knock.bat。
  3. 会弹出一个黑色窗口，浏览器随后自动打开游戏。
     玩的时候别关那个黑色窗口；玩完关掉它就退出了。

如果 Windows 弹出“Windows 已保护你的电脑”
  点“更多信息”→“仍要运行”。这个脚本只是在你自己电脑上开一个本地网页，
  不联网、不安装任何东西。

操作
  W A S D    移动
  Shift      奔跑
  E          互动 / 继续对话
  鼠标       3D 房间里转动视角（先点一下画面）

提示
  - 建议戴耳机，全程约 8 分钟，含突然惊吓。
  - 需要 Windows 10 / 11 和较新的 Chrome 或 Edge 浏览器。
  - 第一次进入要加载约 100MB 素材，标题页会显示进度。
