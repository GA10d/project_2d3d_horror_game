# 敲门 KNOCK — 2D/3D 切换恐怖 Demo

山中小屋里的一段约 8 分钟线性流程：平时是 320×180 的俯视像素画面，进入卧室、地下室和结局时切换成第一人称 3D。

## 运行

```bash
npm install
npm start
```

然后打开 http://localhost:5173 。建议戴耳机。

## 操作

- `WASD` 移动，`Shift` 奔跑，`E` 互动 / 继续对话
- 3D 房间内鼠标转视角（点击画面锁定鼠标），也可用方向键

## 流程

1. 客厅（2D）：拿手电，读爷爷的字条
2. 厨房（2D）：拿地下室钥匙 → 四下敲门声
3. 客厅（2D）：正门自己开了，湿脚印通向走廊
4. 卧室（3D）：开衣柜拿保险丝
5. 走廊（2D）：人影逐次逼近 → 强制闪切 3D
6. 地下室（3D）：装保险丝、扳三个电闸 → 来电 → 灯灭追逐
7. 小屋（2D）：被追着逃向正门 → 三下敲门声
8. 门口（3D）：结局

## 结构

- `src/main.js` 输入、UI、2D/3D 切换、剧情脚本
- `src/world2d.js` 像素小屋（地图、光照、寻路追逐）
- `src/world3d.js` Three.js 房间与各房间的惊吓脚本
- `src/assets.js` 模型 / 贴图加载
- `src/audio.js` 全程序化音效（无音频素材）
- `tools/fetch-assets.mjs` 重新下载 `assets/` 里的素材

## 素材来源
